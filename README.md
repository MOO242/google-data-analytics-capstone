# Bellabeat Case Study – Google Data Analytics Capstone

This project analyzes smart device usage data to identify trends in activity, sleep, and wellness behavior.  
The goal is to provide insights and recommendations to support Bellabeat’s marketing strategy.

## 🔍 Project Highlights
- Cleaned and prepared activity and sleep datasets
- Performed exploratory data analysis (EDA)
- Created visualizations using ggplot2
- Calculated sleep efficiency and weekday patterns
- Merged datasets using R
- Generated insights and business recommendations

## 📁 Files
- `bellabeat_case_study.Rmd` – Full analysis in R Markdown
- `bellabeat_case_study.html` – Rendered report
- `data/` – Raw datasets (if included)

## 🛠 Tools Used
- R
- tidyverse
- ggplot2
- R Markdown

## 📈 Key Insights
- Users average 6,547 steps/day — below recommended levels
- Sleep efficiency varies widely
- Activity and sleep have weak correlations
- Sedentary behavior is high
- Weekday patterns show behavior cycles

## 🟪 Recommendations
- Encourage step‑based challenges
- Improve sleep hygiene coaching
- Personalize notifications by weekday
- Promote holistic wellness features
